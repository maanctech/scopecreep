# Professional User Guide

## Audit Workflow

1. Create the client project and record the hourly rate and project value.
2. Paste or upload the governing SOW in the SOW workspace.
3. Review extraction and AI-assisted risks, edit the boundary map, and approve it yourself.
4. Preview communication imports before confirming them. Importing does not start analysis.
5. Select imported requests and start analysis only after the correct SOW is approved.
6. Review each finding's classification, confidence, quoted evidence, hours, potential revenue, and draft language.
7. Choose a professional decision: bill separately, include in retainer, discuss, absorb, or reject.
8. Set approved hours and amounts separately from the AI estimate before marking an item invoiced.
9. Generate a versioned report and review it before using it in a client conversation.

## Interpretation Rules

`Potential revenue` is an AI estimate. `Approved amount` is a professional-entered billing decision. Neither means the customer agreed to pay. `Needs Human Review` means the evidence or model result is not strong enough for a definitive classification.

ScopeLedger never sends a finding, draft, report, change order, or invoice automatically. Copying or exporting a draft is a deliberate professional action.

## Safe Working Practice

Confirm the selected project and approved SOW before every analysis. Remove irrelevant confidential information before imports where practical. Do not approve a finding on confidence score alone; inspect the cited SOW evidence and request context.
